# 项目文件夹地图

这篇像地图一样介绍每个文件夹。

## 根目录

根目录就是项目最外层。

重要文件：

- `backend/main.py`：服务入口和核心处理类。
- `README.md`：项目原始说明。
- `requirements.txt`：Python 依赖列表。
- `LICENSE`：开源许可证。

## backend/

后端代码。

它负责真正的处理逻辑：

- 读视频
- 找字幕
- 创建遮罩
- 调用修复算法
- 写出新视频
- 合并音频

最重要文件：

- `backend/main.py`
- `backend/config.py`

## backend/inpaint/

修复算法包装代码。

这里不是“找字幕”，而是“把字幕挡住的地方补起来”。

重要文件：

- `sttn_auto_inpaint.py`
- `sttn_det_inpaint.py`
- `lama_inpaint.py`
- `propainter_inpaint.py`
- `opencv_inpaint.py`

## backend/tools/

工具代码。

它们像小工具箱，给主流程提供辅助能力。

例如：

- `subtitle_detect.py`：字幕检测。
- `ocr.py`：OCR 坐标处理。
- `inpaint_tools.py`：遮罩、批处理等工具。
- `ffmpeg_cli.py`：找到系统对应的 ffmpeg。
- `video_io.py`：视频读写。
- `hardware_accelerator.py`：判断 GPU 加速。
- `args_handler.py`：命令行参数。

## backend/models/

模型文件。

这些文件很大，通常是 `.pth`、`.pt`、`.pdiparams` 等。

这里放的是已经训练好的模型。

## backend/ffmpeg/

内置 ffmpeg。

按系统分：

- `macos/`
- `linux_x64/`
- `win_x64/`

## backend/interface/

配置相关文件。

例如：

- `ch.ini`：简体中文。
- `en.ini`：英文。
- `japan.ini`：日文。

## design/

设计资源。

例如：

- 图标
- 演示图片
- 演示 GIF
- 论文 PDF

## test/

测试素材。

里面有示例视频和图片。

## docker/

Docker 构建文件。

主要文件：

- `docker/Dockerfile`

## 你现在只需要记住

看代码时优先看：

```text
backend/main.py
backend/config.py
backend/tools/
backend/inpaint/
```

暂时不要从 `backend/models/` 开始看。
