# 重要文件一览

这篇列出最值得先看的文件。

## 第一层入口

### backend/main.py

后端主入口。

里面的 `SubtitleRemover` 是核心类。

理解这个项目，最终一定会看到它。

## 配置文件

### backend/config.py

保存项目配置。

例如：

- 当前版本号
- 默认语言
- 默认字幕区域
- 默认修复模式
- 硬件加速开关
- STTN 参数
- ProPainter 参数

## 后端处理文件

### backend/tools/subtitle_detect.py

字幕检测。

它用 PaddleOCR 在抽样帧中找出文字框，再整理成字幕时间段。

### backend/tools/inpaint_tools.py

修复辅助工具。

它负责创建遮罩、批量分组等。

### backend/tools/video_io.py

视频读写。

它包含：

- `FramePrefetcher`：提前读取视频帧。
- `FFmpegVideoWriter`：用 ffmpeg 写新视频。

### backend/tools/ffmpeg_cli.py

找到当前系统可用的 ffmpeg 路径。

### backend/tools/hardware_accelerator.py

判断是否能用 GPU 加速。

支持方向包括：

- CUDA
- DirectML
- MPS
- ONNX Runtime Provider

## 修复算法文件

### backend/inpaint/sttn_auto_inpaint.py

STTN 自动区域修复。

### backend/inpaint/sttn_det_inpaint.py

STTN 检测后修复。

### backend/inpaint/lama_inpaint.py

LAMA 修复。

### backend/inpaint/propainter_inpaint.py

ProPainter 修复。

### backend/inpaint/opencv_inpaint.py

OpenCV 自带修复。

## 你现在只需要记住

第一天读代码，只看这 2 个入口就够了：

```text
backend/main.py
backend/config.py
```
