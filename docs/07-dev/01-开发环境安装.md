# 开发环境安装

这篇讲从源码运行项目需要什么。

## 先看 README

项目原始安装说明在：

```text
README.md
```

这里的文档只做简化解释。

## 需要 Python

README 里建议：

```text
Python 3.12+
```

## 创建虚拟环境

虚拟环境可以理解成“给这个项目单独准备一个 Python 小房间”。

创建：

```bash
python -m venv videoEnv
```

macOS 或 Linux 激活：

```bash
source videoEnv/bin/activate
```

Windows 激活：

```bash
videoEnv\Scripts\activate
```

## 安装依赖

项目依赖列表在：

```text
requirements.txt
```

常见安装命令：

```bash
pip install -r requirements.txt
```

但是注意：Torch、Paddle、CUDA 相关依赖，通常要根据你的电脑环境单独安装。

## 为什么安装很麻烦

因为这个项目用到了 AI 模型。

AI 模型可能需要：

- CPU 版本
- NVIDIA CUDA 版本
- Windows DirectML 版本
- macOS Apple Silicon 版本

不同电脑需要不同安装方式。

## 从源码启动命令行

```bash
python backend/main.py -i test/test.mp4 -o test/test_no_sub.mp4
```

## 常见依赖

`requirements.txt` 里有：

- `opencv-python`：视频和图片处理。
- `numpy`：数组处理。
- `paddleocr`：OCR 文字检测。
- `av`：视频相关处理。
- `requests`：网络请求。

## 你现在只需要记住

如果只是使用服务，优先使用 Docker 或打包好的版本。

如果要改代码，才需要折腾源码环境。
