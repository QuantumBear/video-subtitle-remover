# 这是什么项目

## 一句话解释

这是一个去除视频硬字幕和图片文字的服务。

它不是把字幕轨道删除，而是把字幕已经覆盖的画面区域找出来，再根据视频前后帧或图像内容重新补出来。

## 什么是硬字幕

硬字幕已经成为视频画面的一部分，播放时不能单独关闭。字幕、台标、水印和画面中的其他文字都可能属于这一类。

这个项目主要处理硬字幕，不负责编辑外挂字幕文件，也不负责改变字幕轨道内容。

## 它能做什么

项目支持：

- 视频硬字幕去除。
- 图片文字和水印去除。
- 自动检测选区内的文字框。
- 手动指定一个或多个处理区域。
- 选择不同的画面修复算法。
- 批量排队处理多个文件。

需要注意：自动检测找到的是“文字”，不是经过语义判断的“字幕”。如果选区里有 Logo 或水印，它们也可能被处理。

## 它大概怎么做

视频处理可以理解成下面几步：

1. 读取视频帧，并记录分辨率、帧率和帧数。
2. 由调用方指定区域，或用文本检测模型找文字框。
3. 将文字框变成遮罩，告诉模型哪里需要重建。
4. 在字幕出现的时间段内，批量调用修复模型。
5. 将未处理的帧直接写回，将修复后的帧写入临时视频。
6. 从原视频复制音频，合成最终文件。

这不是简单裁剪、涂黑或复制相邻像素，而是对字幕覆盖区域做局部重建。

## 两条主要处理路线

### 直接按选区修复

`sttn-auto` 不做 OCR。它直接把调用方指定的区域作为遮罩，交给 STTN 视频模型处理。

这种方式适合字幕位置固定、能够准确指定区域的普通视频。

### 先检测再修复

`sttn-det`、`lama`、`propainter` 和 `opencv` 会先调用文本检测模型，再修复检测到的时间段和区域。

这种方式更精确，但会受到抽样检测、文字框大小和检测误报的影响。

## 项目入口

- `backend/main.py`：服务处理入口。
- `backend/main.py` 中的 `SubtitleRemover`：整个处理流程的总控。
- `backend/tools/args_handler.py`：命令行参数处理。

## 你现在只需要记住

这个项目的核心工作是：

```text
定位文字区域 -> 生成遮罩 -> 重建被遮挡的画面 -> 合成新视频
```

分辨率通常保持不变，但视频画面会重新编码；“无损分辨率”不等于像素级无损。
