# 最小知识包

这篇只讲理解项目必须知道的最少知识。

## 1. 文件夹是什么

文件夹就是装文件的盒子。

这个项目里最重要的盒子是：

- `backend/`：真正处理视频的代码。
- `backend/models/`：AI 模型文件。
- `backend/ffmpeg/`：处理视频和声音用的 ffmpeg 程序。
- `test/`：测试用的视频和图片。
- `design/`：演示图、论文资料。

## 2. Python 文件是什么

后缀是 `.py` 的文件就是 Python 代码文件。

例如：

- `backend/main.py`
- `backend/config.py`

## 3. 函数是什么

函数可以理解成一个小按钮。

你按一下这个按钮，它就做一件固定的事。

例如 `run()` 这个函数，一般表示“开始运行”。

## 4. 类是什么

类可以理解成一个工具模板。

例如 `SubtitleRemover` 是一个类。它代表“字幕去除器”这个工具。

真正处理一个视频时，程序会用这个模板造出一个实际的字幕去除器对象。

## 5. 服务是什么

这个项目可以作为服务运行。

调用方（例如其他程序或脚本）把视频和参数提交给服务，服务在后台完成处理，并返回进度和结果。

命令行调用是最直接的使用方式，从 `backend/main.py` 开始。

## 6. 后端是什么

后端就是不直接展示给用户看的处理逻辑。

在这个项目里，后端负责：

- 读视频
- 找字幕
- 修复画面
- 写新视频
- 合并声音

主要代码在 `backend/`。

## 7. 模型是什么

模型可以粗略理解成一个已经训练好的“大脑文件”。

项目里的模型负责两类事情：

- 找文字位置。
- 修复被字幕挡住的画面。

模型文件通常很大，所以放在 `backend/models/`。

## 8. 你现在不需要懂的东西

刚开始不用懂这些：

- 深度学习原理
- PaddleOCR 内部怎么识别文字
- STTN、LAMA、ProPainter 的论文细节
- 视频编码原理
- 多进程细节

先知道“它们分别负责哪一步”就够了。
