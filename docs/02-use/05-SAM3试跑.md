# SAM3 mask 试跑

两个根目录脚本使用 **SAM3（非 SAM3.1）逐帧 mask**，绕过 PaddleOCR、GDINO 和 VLM。默认 `caption`、主实例阈值0.5、原图轮廓外扩3px；只有所有提示的主阈值 mask 合并后整帧为空，才采用当前原图的0.3候选。非空帧不追加低分实例，也不复制邻帧轮廓。

在 DGX 项目目录执行：

```bash
./run_sttn.sh input1.mp4 output_sam3_sttn.mp4
./run_sttn_propainter.sh input1.mp4 output_sam3_sttn_propainter.mp4
```

第二个脚本保留 ProPainter 补修预算：全片最多8窗，每窗最多30帧（包含上下文）。只有检测为疑似残留的窗口才补修；mask 漏掉的目标不会被自动发现或补回。

DGX 会优先复用此前已验证的 `quality_eval_20261109/sam3_mask_compare/env/bin/python`、`sam3_code` 和 `sam3_model/sam3.pt`。不在启动时下载模型或修改依赖。在其它机器上，配置安装了官方 SAM3 及流水线依赖的环境和本地文件：

```bash
export SAM3_PYTHON=/path/to/sam3-env/bin/python
export SAM3_CODE_DIR=/path/to/official-sam3
export SAM3_CHECKPOINT=/path/to/sam3.pt
./run_sttn.sh input.mp4 output_sam3_sttn.mp4
```

没有实验目录时，默认使用当前 `python`、`backend/models/sam3/code` 和 `backend/models/sam3/sam3.pt`。权重仍适用 SAM License。

可调整外扩和空帧候选阈值，额外 CLI 参数放在两个视频路径之后：

```bash
./run_sttn.sh input1.mp4 output_sam3_sttn.mp4 --sttn-profile
SAM3_DILATE=2 ./run_sttn.sh input1.mp4 output_sam3_pad2.mp4
# 回退到原始0.5阈值、不外扩、不启用空帧候选：
SAM3_DILATE=0 SAM3_EMPTY_SCORE=0 ./run_sttn.sh input1.mp4 output_sam3_baseline.mp4
# 只关闭空帧候选，保留3px外扩：
SAM3_EMPTY_SCORE=0 ./run_sttn.sh input1.mp4 output_sam3_no_fallback.mp4
```

`SAM3_DILATE`为原视频像素的统一膨胀半径，脚本默认3；增大可覆盖已有目标边缘，但不能找回未检测目标。3px是当前样本的折中值，不是所有分辨率统一最优值。

`SAM3_EMPTY_SCORE`脚本默认0.3，设0禁用；对应 CLI `--sam3-empty-score`。它必须介于0和主阈值之间。同次 SAM3 forward 保留低分实例，只有高阈值合并 mask 整帧为空时采用，不增加图像编码或提示调用次数；低分 mask 的处理仍有计算和内存开销。日志和统计输出 `sam3_empty_frames`（主阈值空帧数）、`sam3_fallback_frames`（启用低阈值候选的帧数）、`sam3_recovered_frames`（由空变为非空的帧数），均在全图外扩和 ROI 裁剪前计数。

`SAM3_SCORE`主阈值仍默认0.5。不建议全局改为0.3，实测会把衣服图案纳入 mask；它与仅空帧采用低分候选的行为不同。若主动降低主阈值，须同时把 `SAM3_EMPTY_SCORE`设为不高于主阈值的值或0。

自定义概念用 `--sam3-prompt caption`；多次传入则共用图像编码、取同一模型的并集。显式传入自定义提示时替代默认caption，如需保留caption须同时传入。空帧判定在所有提示合并后进行，在 ROI 裁剪前进行；主阈值在 ROI 外检出内容时也不会触发空帧候选。

完整视频每帧都做检测，较旧自适应OCR抽帧流程可能更慢。mask以无损PNG暂存在系统临时目录，不在内存/GPU保留全片；完成检测后释放SAM3，再加载STTN。正常或异常退出均清理mask临时目录；进程被强制终止时可能需要清理遗留的 `vsr-sam3-*`。STTN和ProPainter只替换该帧mask内像素，不把轮廓变成外接矩形，也不跨帧扩散mask。

目前只支持 `--inpaint-mode sttn`（含ProPainter残留补修）。直接使用 `python vsr_pipeline.py` 时默认仍为旧检测后端；Python API / CLI 的 SAM3 外扩默认0、空帧候选默认关闭，兼容已有调用。手工启用与两个脚本相同的 mask 配置：

```bash
python vsr_pipeline.py -i input.mp4 -o output.mp4 \
  --device cuda --inpaint-mode sttn --sttn-precision fp16 \
  --mask-backend sam3 --sam3-score 0.5 --sam3-dilate 3 --sam3-empty-score 0.3 \
  --no-locate-stickers --threads 1
```

检查点与源码目录可用上述环境变量设置，或显式传 `--sam3-checkpoint` / `--sam3-code-dir`。

SAM3已知仍会漏emoji、小符号及部分边缘；这是试跑设置，不能当作已经优于现有成片的结论。请重点对照残字、文字描边、emoji、实体贴纸误擦及镜头切换处闪烁。

空帧低分候选不解决已有非空 mask 中的部分实例漏检，淡出细字也可能低于0.3。鞋子、台阶、网格与金属等背景的结构修复痕迹仍需单独检查。下节记录了实际接入的逐帧验证和检测开销。
