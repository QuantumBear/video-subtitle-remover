# 输入输出和任务

这篇讲项目处理哪些文件、输出什么文件、任务怎么理解。

## 支持的输入

项目支持两类输入：

- 视频文件
- 图片文件

判断文件类型的代码在：

```text
backend/tools/common_tools.py
```

里面有两组后缀：

- `video_extensions`
- `image_extensions`

## 视频输出

视频处理完成后，默认输出：

```text
原文件名_no_sub.mp4
```

例如：

```text
test.mp4 -> test_no_sub.mp4
```

也可以用 `-o` 参数指定输出路径。

## 图片输出

图片处理完成后，如果不指定输出路径，默认会放在输入目录下的 `no_sub/` 文件夹。

## 任务是什么

任务就是“一个待处理的文件”。

服务可以一次接收多个视频，对应多个任务。

每个任务有：

- 文件路径
- 进度
- 状态
- 选区设置

## 任务状态

任务状态在代码里叫 `TaskStatus`。

大概有这些：

- 等待处理
- 处理中
- 已完成
- 失败

对应代码：

```text
backend/main.py
```

## 选区是什么

选区就是调用方指定的字幕处理区域。

调用时可以传入“比例坐标”，真正处理前会转成“原视频像素坐标”。

相关代码：

```text
backend/main.py
```

## 你现在只需要记住

一个任务对应一个输入文件。

任务处理完成后，会生成一个新的无字幕文件，不会直接覆盖原文件。
