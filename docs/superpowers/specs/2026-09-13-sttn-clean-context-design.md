# STTN 字幕段干净上下文设计

## 目标

为 STTN 的每个字幕段加入字幕出现前后的干净帧，让时序模型获得未遮挡的参考内容，改善段首、段尾和运动物体附近的修复质量。

## 数据流

当前检测循环只缓存带字幕的帧。改造后，字幕段仍以检测到字幕的连续帧为输出核心，并在核心帧前后各加入固定数量的上下文帧：

- 上下文帧使用原始图像，mask 为全黑；
- 上下文帧参与 STTN 推理和参考帧采样；
- 最终视频只写回核心字幕帧，上下文帧只作为模型输入，不重复输出；
- 场景切换边界不跨越，避免上下文来自不同场景。

## 参数

新增 `STTN_CONTEXT_FRAMES = 8`，表示每侧上下文帧数，取值范围建议 5～15。先用 8 帧验证效果，再根据拖影和耗时调整。

## 分段与输出

处理字幕段时保留上下文帧的原始时间戳和 mask。STTN 返回完整批次后，按帧标记区分上下文与核心帧：上下文结果丢弃，核心帧按现有 ROI 规则写出。上下文帧若因段落边界已经输出过，则不重复加入批次。

## 验证

- 单元测试确认 STTN 收到的批次包含黑 mask 上下文帧；
- 确认输出帧数和 PTS 与输入一致；
- 确认场景切换不把前后场景混入同一批次；
- 在原始 TikSave 视频上对比 baseline 与加入上下文后的字幕残留、拖影和处理耗时。
